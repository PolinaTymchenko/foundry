# create-react-foundry

## 0.1.0

### Minor Changes

- Initial release: `npm create react-foundry` scaffolds a complete React component library monorepo — design tokens as CSS custom properties, `Button` and `Input` components with full keyboard and screen-reader behavior, a working Storybook, an accessibility gate (`eslint-plugin-jsx-a11y` plus axe via Storybook's test runner), Vitest and React Testing Library, and CI wired up via Turborepo and GitHub Actions.
