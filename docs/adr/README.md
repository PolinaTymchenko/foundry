# Architecture Decision Records

Short records of decisions that govern how the component generator (Milestone
3 onward) builds things — not decisions about Foundry's own tooling, which
live in commit history and code comments like anywhere else.

Format: Title, Status, Context, Decision, Consequences. An ADR is superseded,
not edited into silence — if a decision changes, add a new ADR that says so
and mark the old one superseded.
